# Simulations

Les scripts de simulation seront développés dans l'ordre suivant :

1. `01_null_control.R`
2. `02_underfit_states.R`
3. `03_angle_misspecification.R`
4. `04_step_angle_dependence.R`
5. `05_duration_misspecification.R`
6. `06_local_failure.R`
7. `run_all_simulations.R`

Chaque script devra écrire ses sorties dans `results/simulation_tables/` et `results/simulation_figures/`.
