# Gaussian copula log-density

Gaussian copula log-density

## Usage

``` r
gaussian_copula_log_density(u, v, rho)
```

## Arguments

- u, v:

  Numeric vectors with values in `[0, 1]`.

- rho:

  Gaussian copula correlation parameter in `(-1, 1)`.

## Value

A numeric vector of log-density values.
