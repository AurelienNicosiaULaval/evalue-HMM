# Données brutes

Les fichiers de données brutes ne sont pas suivis par Git par défaut.

Documenter ici la source, la licence, la date de téléchargement et les étapes nécessaires pour reconstruire les données brutes.

La première application utilise `moveHMM::elk_data`, qui est chargé directement depuis le package R `moveHMM`. Aucun fichier brut externe n'est téléchargé pour cette version.
